# Junior for Mac

**Never miss a word in lecture.** Live captions, live translation and instant summaries, right at the top of your Mac. Private and offline.

## Download

**[Download Junior.dmg](https://github.com/aarishfaruqii/junior-releases/releases/latest/download/Junior.dmg)**

Latest version: see [Releases](https://github.com/aarishfaruqii/junior-releases/releases).

## What it does

- **Live captions** as the lecturer speaks
- **Live translation** into the language you think in
- **Record-only mode**: hide the panel and Junior keeps listening
- **Instant summaries** of any lecture, even a 2-hour one: Bullets, One line, Summary or Simple English
- **History** keeps full transcripts, **Notes** keeps your summaries, and they stay linked
- Handy extras in the notch: presenting mode, focus mode, keep-awake, calendar, music player, quick tools

## Private by design

Speech recognition, translation and summaries all run on your Mac. Nothing is uploaded and you don't need an account. After the one-time setup, it works offline.

## Install

1. Open `Junior.dmg` and drag **Junior** into **Applications**.
2. First launch: **right-click Junior and choose Open**, then click **Open** again. macOS shows a warning because this early build isn't notarised yet.
3. Allow microphone access when asked. The first time you use translation, macOS downloads the language pack.

## Requirements

- A Mac running a recent version of macOS
- A Mac that supports Apple Intelligence, for summaries

## Verify your download (optional)

Run this in Terminal and compare it with `Junior.dmg.sha256` from the release:

```
shasum -a 256 ~/Downloads/Junior.dmg
```
